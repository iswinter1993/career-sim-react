# 07 — 赛前战术面板 + 暂停/换人交互

**What to build:** 比赛开始前的战术设置界面，以及比赛中暂停后的战术调整和换人交互。3 次换人名额限制，伤病自动暂停。

**Blocked by:** 05 — MatchView 外壳 + CareerView 集成 + 自动模拟

**Status:** ready-for-agent

### 赛前战术面板
- [ ] 比赛开始前显示战术设置面板（替代 Canvas 区域）
- [ ] 阵型选择：4-4-2、4-3-3、3-5-2、4-2-3-1、5-3-2（至少 5 种）
- [ ] 心态选择：全力进攻 / 进攻 / 平衡 / 防守 / 全力防守 → 映射为 team.intent
- [ ] 首发阵容确认：展示 11 个位置的球员姓名，可点击调整
- [ ] 阵型预览：小尺寸战术板显示球员站位
- [ ] "开始比赛"按钮确认设置并启动比赛

### 暂停交互
- [ ] 暂停按钮（比赛进行中可点击）
- [ ] 暂停状态遮罩：半透明遮罩 + "比赛暂停"文字
- [ ] 暂停时引擎停止迭代
- [ ] 暂停时可修改战术（与赛前同一面板，但预设为当前设置）
- [ ] "继续比赛"按钮恢复迭代

### 换人系统
- [ ] 球员受伤时 `injured: true` 自动触发暂停 + 换人提示
- [ ] 换人面板：左右两列，左侧场上球员（当前位置+评分），右侧替补名单
- [ ] 选中场上球员和替补球员，点击确认执行换人
- [ ] 换人后更新 matchState，扣除 1 次换人次数
- [ ] 剩余换人次数 = 0 时禁用换人按钮（伤病换人除外——伤病可强制换人但换人次数已满时无法替换）
- [ ] 换人次数显示：`剩余换人: 2/3`
- [ ] 战术换人也可以主动触发（不限暂停原因）
