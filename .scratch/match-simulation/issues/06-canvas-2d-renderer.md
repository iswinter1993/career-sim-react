# 06 — Canvas 2D 渲染器

**What to build:** 在 MatchView 上区的 Canvas 占位中绘制完整 2D 俯视足球场，包含 22 名球员和球的动画。引擎迭代与渲染帧完全分离。

**Blocked by:** 04 — matchEngine 封装 + GameContext 集成; 05 — MatchView 外壳 + CareerView 集成 + 自动模拟

**Status:** ready-for-agent

### 场地渲染
- [ ] Canvas 自适应容器宽度，高度按 pitchHeight/pitchWidth 比例缩放
- [ ] 草皮底色（绿色）+ 白色标线（边线、底线、中线、中圈、禁区、点球点）
- [ ] 球门框绘制（两端各一个）

### 球员渲染
- [ ] 每名球员用圆形图标表示，填充球队颜色
- [ ] 圆形内显示球衣号码
- [ ] 球员图标旁显示姓名缩写
- [ ] 玩家球员用特殊颜色高亮（金色边框或发光效果）
- [ ] 持球球员显示运动方向箭头（短线指示）

### 球渲染
- [ ] 球以白色小圆点表示，比球员图标略小
- [ ] 球的位置从 matchDetails.ball.position 读取

### 动画循环
- [ ] 独立的 `requestAnimationFrame` 循环，不阻塞引擎迭代
- [ ] 引擎更新 matchDetails 快照 → 渲染层检测新快照 → 从旧位置补间到新位置
- [ ] 补间时长 ~400ms（线性插值）
- [ ] 多帧平滑过渡，无跳跃感
- [ ] 暂停状态下渲染继续但位置冻结
- [ ] 自动模拟模式下不渲染动画

### 性能
- [ ] 60fps 目标帧率
- [ ] 球员数量 22 时无性能退化
- [ ] Canvas 绘制使用离屏缓存避免闪烁
