# 09 — 赛后流程

**What to build:** 比赛结束后的完整收尾——评分展示、属性增长、积分榜更新、返回生涯循环。

**Blocked by:** 02 — 核心纯函数模块; 03 — 随机队友生成 + 阵容构建; 05 — MatchView 外壳 + CareerView 集成 + 自动模拟

**Status:** ready-for-agent

### 赛后评分展示
- [ ] 比赛结束后显示双方球员评分列表
- [ ] 玩家球员评分高亮显示
- [ ] 评分附带简短评价文字（如"7.5 — 表现出色"、"6.0 — 中规中矩"、"5.2 — 状态低迷"）
- [ ] 最佳球员（双方最高分）加星标
- [ ] 评分在 0-10 范围内显示为带颜色的进度条

### 属性增长
- [ ] `applyMatchGrowth(attrs, rating, position, potential)` 函数
- [ ] 评分 > 7.0 触发增长
- [ ] 增长量 = f(评分, 位置权重, 潜力剩余空间)
- [ ] 增长与赛季 `tickAttributes` 叠加（加法关系）
- [ ] 增长后被潜力值封顶
- [ ] 展示增长 deltas（哪些属性加了多少）
- [ ] 增长使用 `pendingResult.deltas` 格式与现有事件结果面板兼容

### 积分榜更新
- [ ] 比赛结果写入联赛积分榜

- [ ] 侧边栏积分榜刷新排名
- [ ] 积分榜嵌入在比赛页面 Tab 面板中

### 返回生涯

- [ ] 清理 matchState，回到生涯循环
- [ ] 引擎继续生成下一个 pending 步骤
