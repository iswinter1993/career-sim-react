# 08 — 播报系统 + 关键技术统计 Tab

**What to build:** 比赛中的实时文字播报滚动流、关键时刻弹出提示、技术统计面板的完整数据展示。

**Blocked by:** 05 — MatchView 外壳 + CareerView 集成 + 自动模拟

**Status:** ready-for-agent

### 播报系统
- [ ] 底部滚动文字流，实时显示 matchDetails.iterationLog 中的事件
- [ ] 每条播报包含时间标记（映射为比赛分钟）+ 文字描述
- [ ] 中文播报模板：如"第 23 分钟，张三传球给李四"
- [ ] 自动滚动到最新播报
- [ ] 关键事件弹出提示（屏幕中央半透明提示，2 秒后自动消失）：
  - 进球："⚽ 进球！李四 第 35 分钟"
  - 红牌："🟥 红牌！张三被罚下"
  - 伤病："🏥 王五受伤"
  - 扑救："🧤 精彩扑救！"
  - 点球："🔴 点球！"
- [ ] 弹出提示有入场/出场动画（fade in + fade out）

### 技术统计 Tab
- [ ] 双方对比表格（主队 vs 客队）
- [ ] 指标：控球率(%)、射门（总数/射正/射偏）、传球（总数/成功/失败）、抢断（成功/失败）、角球、犯规、黄牌/红牌、跑动距离(km)、传球成功率(%)
- [ ] 柱状图或条形图可视化关键指标对比
- [ ] 统计数据从 matchDetails 的 team statistics 和 player stats 聚合计算
- [ ] 跑动距离根据球员每次迭代移动量累积估算
- [ ] 传球成功率 = 成功传球 / 总传球 × 100%
- [ ] 半场时也展示统计数据
