# Phase 1.2: 改造 setFreekicks.js — 12位置任意球站位

**Phase**: 1 (12位置引擎改造)
**优先级**: P1
**阻塞**: P0.3 (positionGroup.js)
**被阻塞**: 无

---

## 描述

将 `engine/lib/setFreekicks.js` 中所有10个函数的硬编码位置数组替换为 `positionGroup.js` 的分组函数。确保 CDM/CAM/LW/RW 在任意球防守和进攻站位中被正确分配。

## 背景分析

`setFreekicks.js` 有10个公开函数，每个函数都使用硬编码的位置数组进行分类：
- 防守方站位: `['GK', 'CB', 'LB', 'RB']` — 守门员+防线，**缺失CDM**
- 中场站位: `['CM', 'LM', 'RM']` — **缺失CAM**
- 前锋站位: 默认为"else"分支（ST等），**LW/RW未被显式分组**

任意球区域分为5个(Y方向分层)：门前(0-100)、前场(100-Halfway)、中场(Halfway-3/4)、后场(3/4-禁区边)、禁区附近。

## 实现内容

### 文件: `D:\newgame\career-sim-react\src\engine\lib\setFreekicks.js`

1. **添加导入**:
   ```javascript
   import { getPositionGroup, getSetpieceGroup, isInGroup, isDefensivePosition, isMidfieldPosition, isAttackingPosition } from './positionGroup.js';
   ```

2. **替换模式**（~50处）:

   **防守方球员分类**:
   ```
   旧: if (['GK', 'CB', 'LB', 'RB'].includes(player.position))
   新: if (isInGroup(player.position, 'BACK_LINE') || player.position === 'GK')
   
   或更精确:
   旧: player.currentPOS = player.originPOS.map(x => x)  // 防线不动
   新: if (isDefensivePosition(player.position)) // CDM也会被包含
         player.currentPOS = player.originPOS.map(x => x)
   ```

   **中场球员分类**:
   ```
   旧: else if (['CM', 'LM', 'RM'].includes(player.position))
   新: else if (isMidfieldPosition(player.position))
        // 包含 CM, CAM, LM, RM
   ```

   **进攻球员分类**:
   ```
   旧: else { ... } // 默认——ST
   新: else if (isAttackingPosition(player.position))
        // 包含 ST, LW, RW, CAM(部分情况)
   ```

3. **新位置的特殊站位规则**:

   | 任意球区域 | CDM | CAM | LW/RW |
   |-----------|-----|-----|-------|
   | 本方禁区附近(lowerFinalQtr) | 同CB参与人墙 | 随机禁区前沿站位准备反击 | 随机禁区边站位准备反击 |
   | 本方3/4区域(upperFinalQtr) | 同CB防线站位 | 同CM站位在禁区外 | 同CM站位偏边路 |
   | 中场区域 | 同CM站位 | 同CM站位略靠前 | 同LM/RM站位 |
   | 前场区域 | 在后方保护 | 参与进攻站位 | 参与进攻站位偏边路 |
   | 对方禁区附近(100YPos) | 中场线站位 | 禁区边缘站位 | 禁区边缘站位 |

4. **具体函数修改清单**:
   - `setTopOneHundredYPos` — 进攻/防守球员分配（~6处修改）
   - `setBottomOneHundredYPos` — 同上
   - `setTopOneHundredToHalfwayYPos` — 防守球员/中场/前锋分类（~10处修改）
   - `setBottomOneHundredToHalfwayYPos` — 同上
   - `setTopHalfwayToBottomQtrYPos` — 同上
   - `setBottomHalfwayToTopQtrYPos` — 同上
   - `setTopBottomQtrCentreYPos` — 人墙+禁区站位分配（~8处修改）
   - `setBottomUpperQtrCentreYPos` — 同上
   - `setTopLowerFinalQtrBylinePos` — 防守站位（~6处修改）
   - `setBottomLowerFinalQtrBylinePos` — 同上
