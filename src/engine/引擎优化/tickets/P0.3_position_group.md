## 描述

创建 `engine/lib/positionGroup.js` 工具模块，提供位置分组判断、位置分类、位置比较等核心工具函数。所有引擎模块（actions.js, setFreekicks.js, setPositions.js, playerMovement.js）将通过此模块统一引用位置分组逻辑。

## 背景

当前引擎中位置分组逻辑硬编码在各文件中：
- `['CB', 'LB', 'RB']` — 出现在setFreekicks.js和setPositions.js的~40处
- `['CM', 'LM', 'RM']` — 出现~30处
- `position === 'GK'` — 出现~25处
- 新增的CDM/CAM/LW/RW在这些分组中完全不被识别

集中管理位置分组是实现12位置完整改造的前提。

## 实现内容

### 文件: `D:\newgame\career-sim-react\src\engine\lib\positionGroup.js`

```javascript
// 位置分组定义
const GROUP_DEFINITIONS = {
  GK:  ['GK'],
  CB:  ['CB'],
  FB:  ['LB', 'RB'],
  DM:  ['CDM'],
  CM:  ['CM', 'CAM'],
  WM:  ['LM', 'RM'],
  WG:  ['LW', 'RW'],
  ST:  ['ST'],
};

// 特殊分组（用于定位球）
const SETPIECE_GROUPS = {
  DEFENDERS:      ['GK', 'CB', 'LB', 'RB', 'CDM'],
  MIDFIELDERS:    ['CM', 'CAM', 'LM', 'RM'],
  ATTACKERS:      ['ST', 'LW', 'RW'],
  WIDE_PLAYERS:   ['LB', 'RB', 'LM', 'RM', 'LW', 'RW'],
  CENTRAL_PLAYERS: ['GK', 'CB', 'CDM', 'CM', 'CAM', 'ST'],
  BACK_LINE:      ['CB', 'LB', 'RB'],
};
```

2. **核心API函数**:
   - `getPositionGroup(position)` → 'GK'|'CB'|'FB'|'DM'|'CM'|'WM'|'WG'|'ST'
   - `isInGroup(position, groupName)` → boolean
   - `isDefensivePosition(position)` → 是否后防线球员
   - `isMidfieldPosition(position)` → 是否中场球员
   - `isAttackingPosition(position)` → 是否进攻球员
   - `isWidePosition(position)` → 是否边路球员（含LB/RB/LWB/RWB/LM/RM/LW/RW）
   - `isCentralPosition(position)` → 是否中路球员
   - `getSetpieceGroup(position, groupName)` → 定位球分组判断
   - `ALL_POSITIONS` → 12个位置的数组常量
   - `POSITION_LABELS` → 12个位置的中文标签映射

3. **定位球层级分组**（用于任意球站位分配）:
   - `getSetpieceLayer(position, ballZone)` → 'wall'|'near_post'|'far_post'|'edge_of_box'|'stay_forward'
   - 根据位置和任意球区域决定该球员应承担的角色
