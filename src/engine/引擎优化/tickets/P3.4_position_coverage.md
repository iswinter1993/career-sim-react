# Phase 3.4: 实现位置覆盖逻辑 — 换人后的位置重新映射

**Phase**: 3 (FM级别换人)
**优先级**: P3
**阻塞**: P0.3 (positionGroup.js), P3.1 (substitution)
**被阻塞**: 无

---

## 描述

当替换球员和被替换球员的位置不匹配时（如 ST 换下 CM），引擎需要正确处理位置重新映射。本ticket实现 `resolveSubstitutionPosition()` 函数，决定替补球员在换人后实际扮演什么位置角色。

## 背景

FM中换人后的实际位置取决于：
1. 战术角色熟悉度（球员能否适应新位置）
2. 球队阵型需求（新阵型下该角色的存在性）
3. 同位置其他球员的覆盖能力

例如：4-4-2阵型中，ST换下CM → 替补ST打哪？
- 如果阵型变为4-4-1-1，ST可以打影子前锋
- 如果保持4-4-2，ST被迫打CM（失位惩罚）

## 实现内容

### 文件: `D:\newgame\career-sim-react\src\engine\lib\positionGroup.js` 中的新增函数

```javascript
/**
 * Resolve a substitute's effective position after a substitution.
 * Returns both the assigned position and any familiarity penalty.
 *
 * @param {object} playerIn — substitute player (has .position field)
 * @param {object} playerOut — player being replaced
 * @param {string} formation — current formation
 * @returns {{effectivePosition: string, familiarityModifier: number}}
 *   familiarityModifier: 1.0 (native), 0.85 (accomplished), 0.70 (competent), 0.50 (awkward)
 */
export function resolveSubstitutionPosition(playerIn, playerOut, formation) {
  const inPos = playerIn.position;
  const outPos = playerOut.position;
  
  // 1. Same position — perfect fit
  if (inPos === outPos) {
    return { effectivePosition: outPos, familiarityModifier: 1.0 };
  }
  
  // 2. Same group — natural fit
  const inGroup = getPositionGroup(inPos);
  const outGroup = getPositionGroup(outPos);
  
  if (inGroup === outGroup) {
    return { effectivePosition: outPos, familiarityModifier: 0.90 };
  }
  
  // 3. Adjacent group — reasonable fit
  // e.g., CM → CAM (MID → AM group), LB → LM (FB → WM group)
  if (areAdjacentGroups(inGroup, outGroup)) {
    return { effectivePosition: outPos, familiarityModifier: 0.75 };
  }
  
  // 4. Cross-group — awkward fit
  // e.g., ST → CB (FWD → DEF group)
  return { effectivePosition: outPos, familiarityModifier: 0.45 };
}

/**
 * Determine if two position groups are tactically adjacent.
 */
function areAdjacentGroups(groupA, groupB) {
  const adjacency = {
    'GK': ['DEF'],
    'DEF': ['GK', 'DM', 'WB'],
    'DM': ['DEF', 'MID'],
    'MID': ['DM', 'AM'],
    'AM': ['MID', 'WG'],
    'WG': ['AM', 'FWD'],
    'WB': ['DEF', 'WG'],
    'FWD': ['WG', 'AM'],
  };
  return (adjacency[groupA] || []).includes(groupB);
}

/**
 * Calculate skill modifier based on position familiarity.
 * Modifies the player's effective skill scores during the match.
 *
 * @param {object} player — player with skills
 * @param {number} familiarityModifier — from resolveSubstitutionPosition
 * @returns {object} adjusted skills
 */
export function applyFamiliarityPenalty(player, familiarityModifier) {
  if (familiarityModifier >= 1.0) return player;
  
  const penalty = 1.0 - familiarityModifier;
  return {
    ...player,
    pace: player.pace * (1.0 - penalty * 0.4),
    shooting: player.shooting * (1.0 - penalty * 0.6),
    passing: player.passing * (1.0 - penalty * 0.5),
    dribbling: player.dribbling * (1.0 - penalty * 0.6),
    tackling: player.tackling * (1.0 - penalty * 0.7),
    positioning: player.positioning * (1.0 - penalty * 0.8), // positioning suffers most
    strength: player.strength * (1.0 - penalty * 0.3),
  };
}
```
