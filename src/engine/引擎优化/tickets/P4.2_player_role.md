## 描述

在 `engine/lib/tactics.js` 中完成 PlayerRole 的实现。这是FM三层AI的第二层——每个球员在具体位置上的战术角色，决定该球员的动作权重和移动倾向。

## 背景

FM中每个位置有多种可选角色。例如CM位置：
- **Deep-Lying Playmaker (DLP)**: 更深的站位，更多防守+组织，少射门
- **Box-to-Box Midfielder (B2B)**: 全面覆盖，均衡攻防，频繁跑动
- **Mezzala**: 边路倾向，更多前插
- **Advanced Playmaker**: 进攻组织者，更多传球+盘带
- **Ball-Winning Midfielder (BWM)**: 更多抢断+拦截，少参与进攻

角色修改器主要影响：动作权重倍率、移动倾向参数、体能消耗速率。

2. **getRoleModifier(roleKey) → 查询API**

```javascript
/**
 * Get the action and movement modifiers for a given role.
 * @param {string} roleKey — e.g. 'CM_box_to_box_support'
 * @returns {{actionModifiers: object, movementModifiers: object, position: string|string[], duty: string}}
 */
export function getRoleModifier(roleKey) {
  return PLAYER_ROLES[roleKey] || PLAYER_ROLES['CM_box_to_box_support']; // fallback
}
```

3. **validateRoleForPosition(roleKey, position) → boolean**

```javascript
export function validateRoleForPosition(roleKey, position) {
  const role = PLAYER_ROLES[roleKey];
  if (!role) return false;
  const allowedPos = role.position;
  if (Array.isArray(allowedPos)) return allowedPos.includes(position);
  return allowedPos === position;
}
```

4. **getAvailableRolesForPosition(position) → roleKey[]**

```javascript
export function getAvailableRolesForPosition(position) {
  return Object.entries(PLAYER_ROLES)
    .filter(([, role]) => {
      const allowed = role.position;
      return Array.isArray(allowed) ? allowed.includes(position) : allowed === position;
    })
    .map(([key]) => key);
}
```

5. **getDefaultRole(position) → roleKey**

```javascript
export function getDefaultRole(position) {
  const defaults = {
```
