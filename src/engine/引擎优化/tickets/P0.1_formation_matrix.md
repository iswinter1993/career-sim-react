## 描述

创建 `engine/lib/formation.js` 模块，作为阵型坐标的唯一真理源（Single Source of Truth）。该模块包含10+种标准足球阵型的精确11人位置坐标矩阵，以及阵型坐标查询和计算的公共API。

## 背景

当前阵型坐标分散在三个地方且互不一致：
1. `matchEngine.js` 的 `POSITION_PLACES` 静态表（引擎实际使用，仅12个坐标）
2. `TacticsPanel.jsx` 的 `FORMATIONS` 对象（UI视觉展示，百分比坐标）
3. `squadGen.js` 的 `FORMATIONS` 对象（生成球队时使用的位置名数组）

这导致4-3-3和4-4-2中的CM球员具有完全相同的originPOS，阵型的战术效果无法体现。

## 实现内容

### 文件: `D:\newgame\career-sim-react\src\engine\lib\formation.js`

1. **阵型坐标矩阵** `FORMATION_MATRIX` — 至少10种阵型的 {slot: {x, y}} 映射:
   - 4-4-2, 4-3-3, 4-2-3-1, 3-5-2, 5-3-2 (现有5种)
   - 4-1-4-1, 3-4-3, 4-4-1-1 (新增3种)
   - 4-3-2-1 (Christmas Tree), 3-4-2-1 (新增2种)
   - 坐标基于 pitchWidth=680, pitchHeight=1050

2. **核心API函数**:
   - `getFormationSlots(formationName)` → 阵型的位置槽位数组 [{pos, x, y, slotKey}]
   - `getFormationPositions(formationName, pitchSize, mentality)` → {positionKey: [x,y]}
   - `computeOriginPOSForStarters(starters, formationName, pitchSize)` → [[x,y], ...]
   - `getAdjustedLineY(baseY, mentality, pitchHeight)` → mentality调节后的Y坐标
   - `getAvailableFormations()` → 所有可用阵型名称列表
   - `getFormationLabel(formationName)` → 阵型中文标签

3. **Mentality线深调节**: 进攻心态下防线前移(+7%)，防守心态下防线后撤(-7%)，全力进攻/防守下±15%

## 验收标准

- [ ] 包含至少10种阵型的坐标定义
- [ ] 每个阵型包含恰好11个位置槽位
- [ ] `getFormationSlots('4-3-3')` 返回正确的11个位置槽
- [ ] 心态参数正确调节Y坐标（attack前移，defend后撤）
- [ ] 作为纯模块无副作用，导出所有公共API
