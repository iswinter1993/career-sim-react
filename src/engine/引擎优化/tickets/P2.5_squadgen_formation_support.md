# Phase 2.5: 重构 squadGen — 支持16种阵型的阵容生成

**Phase**: 2 (动态阵型引擎)
**优先级**: P2
**阻塞**: P0.1 (formation.js), P0.3 (positionGroup.js)
**被阻塞**: 无 (独立模块)

---

## 描述

重构 `squadGen.js` 的阵容生成功能，使其能够：
1. 生成符合任意阵型位置要求的16人（11首发+5替补→7替补）球队
2. 替补池从5人扩展到7人并覆盖所有位置
3. 阵型选择从 `FORMATIONS` 中随机抽取（使用 formation.js 的列表）

## 背景

当前 `squadGen.js` 的 `FORMATIONS` 对象只有5种阵型（简单的position name数组），`SUB_POSITION_POOL` 只覆盖5种位置，生成算法不保证替补多样性。

   ```javascript
   // 新: 7人替补池，覆盖所有位置组
   const SUB_POSITION_TEMPLATES = [
     // 模板1: 标准 bench — 1GK + 2DEF + 2MID + 1WIDE + 1FWD
     ['GK', 'CB', 'LB', 'CM', 'CAM', 'LW', 'ST'],

     ['GK', 'CB', 'CM', 'CAM', 'LW', 'RW', 'ST'],

   function getRandomBenchTemplate(rng) {
     return SUB_POSITION_TEMPLATES[Math.floor(rng() * SUB_POSITION_TEMPLATES.length)];
   }
   ```

   ```javascript
   export function buildTeamSquad(seed, formationName) {
     const rng = seedrandom(seed);
     const formation = formationName || availableFormations[Math.floor(rng() * availableFormations.length)];
     
     // 1. 从阵型获取位置需求
     const formationSlots = getFormationSlots(formation);
     const starterPositions = formationSlots.map(s => s.pos);
     
     // 2. 生成16人（11首发 + 5替补 → 过渡到18人）

   }
   ```
