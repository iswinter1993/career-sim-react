# Phase 2.4: 重构 TacticsPanel — 10+阵型选择器

**Phase**: 2 (动态阵型引擎)
**优先级**: P2
**阻塞**: P0.1 (formation.js基础矩阵), P2.1 (formation API)
**被阻塞**: 无

---

## 描述

重构 `TacticsPanel.jsx` 的阵型选择UI，将现有的5种阵型扩展为10+种阵型的可视化选择器，支持赛中变阵按钮和阵型预览。

## 背景

当前 `TacticsPanel.jsx` 的 `FORMATIONS` 对象只有5种阵型（4-4-2, 4-3-3, 3-5-2, 4-2-3-1, 5-3-2），且阵型坐标是手动编写的百分比值。需要对接 `formation.js` 获取完整阵型列表和坐标。

## 实现内容

### 文件: `D:\newgame\career-sim-react\src\components\TacticsPanel.jsx`

1. **导入 formation API**:
   ```javascript
   import { getAvailableFormations, getFormationLabel, getFormationSlots } from '../engine/lib/formation.js';
   ```

2. **替换 FORMATIONS 常量**:

   删除旧的硬编码 `FORMATIONS` 对象，改用 `formation.js` 的数据:
   ```javascript
   // 在组件内动态构建
   const formations = useMemo(() => {
     const names = getAvailableFormations();
     return names.map(name => {
       const slots = getFormationSlots(name);
       return {
         key: name,
         label: getFormationLabel(name),
         slots, // [{pos, slotKey, x, y}, ...]
       };
     });
   }, []);
   ```

3. **扩展阵型选择器UI**:

   - 增加阵型数量到10+种（4-1-4-1, 4-4-1-1, 4-2-4, 3-4-3, 3-6-1 等）
   - 每个阵型用预设的11个圆点组成的迷你战术板预览
   - 网格布局：每行4-5个阵型卡片

4. **MiniBoard SVG组件优化**:

   - 接收 `slots` 数据（来自 formation.js），而非手动百分比
   - 每个位置绘制为对应颜色的小圆点
   - 连接线显示阵型层次感（GK线、后卫线、中场线、锋线）
   - 当前选中阵型高亮显示

5. **心态选择器增强**:

   - 5级可选：ultra_attack / attack / balanced / defend / ultra_defend
   - 每个选项带颜色条（红→蓝渐变）
   - 显示对防线高度的影响

6. **赛中变阵按钮**（新增）:

   在 PreMatchTactics 组件外，MatchView 中增加赛中暂停时的变阵触发:
   ```jsx
   function InMatchFormationPanel({ currentFormation, onFormationChange }) {
     const [selected, setSelected] = useState(currentFormation);
     return (
       <div className="formation-panel">
         {formations.map(f => (
           <button key={f.key} 
             className={`formation-btn ${selected === f.key ? 'active' : ''}`}
             onClick={() => { setSelected(f.key); onFormationChange(f.key); }}>
             <MiniBoard slots={f.slots} />
             <span>{f.label}</span>
           </button>
         ))}
       </div>
     );
   }
   ```
