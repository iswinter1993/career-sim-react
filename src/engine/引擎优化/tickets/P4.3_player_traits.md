## 描述

在 `engine/lib/tactics.js` 中实现 PlayerTraits 系统——这是FM三层AI的第三层（最细粒度），定义球员的个人风格和倾向性，在角色规则之上覆盖特定行为。

## 背景

FM中的Traits（习惯/特质）是球员的"个人风格"——与角色和战术指令独立，是球员自带的天然倾向。例如：
- **Plays One-Twos**: 更多二过一配合 → 增加 `pass` 权重 + 减少 `dribble`
- **Tries Killer Balls Often**: 更多直塞 → 增加 `throughBall` 权重
- **Shoots From Distance**: 远射倾向 → 增加 `shoot` 权重（当球在禁区外时）
- **Comes Deep To Get Ball**: 回撤接球 → 调整 intentPOS 更靠后
- **Gets Into Opposition Area**: 前插禁区 → 增加 `run` 权重 + 调整 intentPOS 更靠前
- **Cuts Inside From Both Flanks**: 内切 → 调整 X轴偏移 + `cutInside` movement modifier
- **Dictates Tempo**: 控制节奏 → 覆盖 team tempo
- **Tries To Play Way Out Of Trouble**: 盘带出险 → 增加 `dribble` 在被压迫时
- **Stays Back At All Times**: 从不前插 → 设置 `forwardRuns: 0`
- **Marks Opponent Tightly**: 紧逼盯人 → 调整 intentPOS 跟随对位球员

总共约30个Traits，分为几类：
- **Movement traits** (影响 intentPOS): Comes Deep, Gets Forward, Stays Back, Cuts Inside, Hugs Line, Moves Into Channels
- **Action traits** (影响动作权重): Plays One-Twos, Killer Balls, Shoots From Distance, Runs With Ball, Dwells On Ball, Long Range Passes, Long Flat Throw
- **Reaction traits** (影响响应): Winds Up Opponents, Argues With Officials, Dictates Tempo, Tries To Play Way Out Of Trouble
- **Marking traits**: Marks Opponent Tightly, Does Not Dive Into Tackles

2. **核心API**:

```javascript
/**
 * Evaluate all traits for a player and return combined modifiers.
 * Called during action selection and movement calculation.
 *
 * @param {object} player — player with traits array
 * @param {object} matchState — current match state (for conditional traits)
 * @returns {{actionModifiers: object, movementModifiers: object, flags: string[]}}
 */
export function evaluateTraits(player, matchState) {
  if (!player.traits || !Array.isArray(player.traits)) {
    return { actionModifiers: {}, movementModifiers: {}, flags: [] };
  }
  
  const combined = {
    actionModifiers: {},
    movementModifiers: {},
    flags: [],
  };
  
  for (const traitKey of player.traits) {
    const trait = PLAYER_TRAITS[traitKey];
    if (!trait) continue;
    
    // Check condition — trait only fires when its condition is met
    if (trait.condition && !trait.condition(player, matchState)) continue;
    
    const { override } = trait;
    
    // Merge action modifiers (additive)
    if (override.actionModifiers) {
      for (const [key, val] of Object.entries(override.actionModifiers)) {
        combined.actionModifiers[key] = (combined.actionModifiers[key] || 0) + val;
      }
    }
    
    // Merge movement modifiers (additive)
    if (override.movementModifiers) {
      for (const [key, val] of Object.entries(override.movementModifiers)) {
        combined.movementModifiers[key] = (combined.movementModifiers[key] || 0) + val;
      }
    }
    
    // Collect flags
    if (override.flag) {
      combined.flags.push(override.flag);
    }
  }
  
  return combined;
}
```
