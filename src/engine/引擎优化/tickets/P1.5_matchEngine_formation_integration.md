# Phase 1.5: 改造 matchEngine.js — 集成阵型计算originPOS

**Phase**: 1 (12位置引擎改造)
**优先级**: P1
**阻塞**: P0.1 (formation.js), P0.4 (validate.js)
**被阻塞**: P2.2, P2.3, P3.1, P4.5

---

## 描述

重构 `matchEngine.js` 中的 `_placementFor()` 和 `buildPlayerJson()` 函数，使其使用 `formation.js` 的阵型坐标矩阵来计算球员的 originPOS，替代现有的静态 `POSITION_PLACES` 表。同时扩展 `createMatch()` 接受完整的战术配置（阵型、角色、策略）。

## 背景

当前流程：
1. `_placementFor(p)` 查静态 `POSITION_PLACES` 表获取位置基础坐标
2. `PAIRED_OFFSET_X` 对双位置(CB×2, CM×2等)交替X坐标
3. 无论什么阵型，CM的originPOS都是 [230, 270] 或 [420, 270]
4. 阵型信息仅存在 `matchDetails._homeFormation` 中，不影响坐标

改造后：
1. 阵型决定坐标 → `formation.js` 的矩阵查询
2. 位置映射到阵型槽位 → `computeOriginPOSForStarters()`
3. originPOS随阵型变化 → 4-3-3的CM站位不同于4-4-2的CM

## 实现内容

### 文件: `D:\newgame\career-sim-react\src\matchEngine.js`

1. **导入新模块**:
   ```javascript
   import { getFormationPositions, computeOriginPOSForStarters } from './engine/lib/formation.js';
   import { getDefaultRole } from './engine/lib/tactics.js';
   import { ALL_POSITIONS } from './engine/lib/positionGroup.js';
   ```

2. **替换 `_placementFor()` 函数**:

   旧逻辑：查 `POSITION_PLACES` 表 + `PAIRED_OFFSET_X` 交替
   新逻辑：调用 `computeOriginPOSForStarters()` 获取整队坐标数组

3. **扩展 `buildPlayerJson()` 函数**:

   新增参数 `originPOS`（可选覆盖），新增字段 `role`:
   ```javascript
   export function buildPlayerJson(p, originPOS) {
     const [px, py] = originPOS || _getDefaultPlacement(p.position);
     return {
       // ...existing fields...
       originPOS: [px, py],  // 现在由formation.js计算
       role: p.role || getDefaultRole(p.position),  // 新增
     };
   }
   ```

4. **扩展 `buildTeamJson()` 函数**:

   新增参数 `tactics`（包含formation, strategy, roles）:
   ```javascript
   export function buildTeamJson(teamName, players, tactics) {
     const formation = tactics?.formation || '4-4-2';
     const originPOSList = computeOriginPOSForStarters(players, formation);
     
     return {
       name: teamName,
       players: players.map((p, i) => buildPlayerJson({...p, role: tactics?.roles?.[p.id]}, originPOSList[i])),
       manager: 'CPU',
     };
   }
   ```

5. **扩展 `createMatch()` 函数**:

   新增参数 `tactics`，包含:
   - `homeFormation`, `awayFormation` — 阵型名称
   - `homeMentality`, `awayMentality` — 心态（已有）
   - `homeStrategy`, `awayStrategy` — 球队策略（新增，传给tactics.js）
   - `homeRoles`, `awayRoles` — 球员角色映射（新增，{playerID: roleName}）

   ```javascript
   export async function createMatch(homeTeam, awayTeam, pitch, tactics) {
     // 1. 应用 mentality（现有逻辑）
     const ht = tactics?.homeMentality ? applyMentalityToTeam(homeTeam, tactics.homeMentality) : homeTeam;
     const at = tactics?.awayMentality ? applyMentalityToTeam(awayTeam, tactics.awayMentality) : awayTeam;
     
     // 2. 应用 team strategy（新增）
     if (tactics?.homeStrategy) {
       applyTeamStrategy(ht, tactics.homeStrategy, pitch || DEFAULT_PITCH);
     }
     
     // 3. 初始化引擎（现有逻辑）
     const md = await Engine.initiateGame(ht, at, p);
     
     // 4. 存储战术元数据
     md._homeFormation = tactics?.homeFormation || '4-4-2';
     md._awayFormation = tactics?.awayFormation || '4-4-2';
     md._homeStrategy = tactics?.homeStrategy || {};
     md._awayStrategy = tactics?.awayStrategy || {};
     md._homeRoles = tactics?.homeRoles || {};
     // ...existing tags...
     
     return md;
   }
   ```

6. **保留 POSITION_PLACES 作为回退**:

   在 `formation.js` 不可用或阵型未知时，回退到现有的静态表。
