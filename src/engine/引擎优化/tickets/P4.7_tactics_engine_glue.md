# Phase 4.7: 战术引擎粘合层 — 将所有AI组件接入主循环

**Phase**: 4 (Three-Layer AI)
**优先级**: P3
**阻塞**: P4.1-P4.6 (所有前面的AI tickets)
**被阻塞**: P5.1 (ratings需要战术数据)

## 描述

在所有引擎组件之间创建粘合层，确保战术数据（strategy, roles, traits）在比赛循环中正确流动和持久化。这个ticket不新增功能，而是确保所有独立模块正确连接。

## 背景

P4.1-P4.6创建了多个独立组件：
- tactics.js: TeamStrategy presets, PlayerRole definitions, PlayerTraits definitions
- actions.js: 动作权重被角色/特质修改
- playerMovement.js: 移动行为被策略/角色/特质修改
- formation.js: originPOS被策略的防线高度影响
- TacticsPanel: UI收集用户战术选择
- MatchView: 赛中战术变化触发

但是这些组件之间没有一个统一的接口和数据流。此ticket的作用类似胶水——确保数据从UI→matchEngine→引擎模块无缝流动。

1. **创建 `buildMatchTactics(squad, uiTactics)` 统一入口**:

```javascript
import { STYLE_PRESETS, getDefaultRole } from './engine/lib/tactics.js';

/**
 * Build the complete tactics configuration for a match.
 * Merges UI-selected tactics with squad defaults.
 *
 * @param {object} squad — team squad from squadGen
 * @param {object} uiTactics — user-selected tactics {formation, style, mentality, roles}
 * @returns {object} — complete tactics ready for createMatch()
 */
export function buildMatchTactics(squad, uiTactics) {
  const formation = uiTactics?.formation || squad.formation || '4-4-2';
  const style = uiTactics?.style || 'balanced';
  const mentality = uiTactics?.mentality || 'balanced';
  
  // Resolve style — can be a preset key or raw strategy object
  const strategy = typeof style === 'string'
    ? (STYLE_PRESETS[style] || STYLE_PRESETS.balanced)
    : style;
  
  // Resolve roles — fill in defaults for positions without explicit role
  const roles = {};
  const starters = squad.starters || squad.players?.slice(0, 11) || [];
  for (const player of starters) {
    roles[player.playerID || player.id] = 
      uiTactics?.roles?.[player.playerID || player.id] || 
      getDefaultRole(player.position);
  }
  
  return {
    formation,
    strategy,
    mentality,
    roles,
  };
}
```

2. **创建 `injectTacticsIntoTeam(team, tactics)` 辅助**:

```javascript
/**
 * Inject tactics data into team players for use during simulation.
 * This sets up each player's role reference and stores the strategy on the team.
 */
export function injectTacticsIntoTeam(team, tactics) {
  // Store strategy on team object
  applyTeamStrategy(team, tactics.strategy, /* pitch size from context */);
  
  // Assign roles to players
  const players = team.players || [];
  for (const player of players) {
    const playerId = player.playerID || player.id;
    player.role = tactics.roles[playerId] || getDefaultRole(player.position);
    // traits should already be on the player from squadGen, but ensure array
    if (!player.traits) player.traits = [];
  }
  
  return team;
}
```

3. **重构 `createMatch()` 完整流程**:

```javascript
export async function createMatch(homeTeam, awayTeam, pitch, tactics) {
  const p = pitch || DEFAULT_PITCH;
  
  // Step 1: Apply mentality (existing logic — skill modifiers)
  const ht = tactics?.homeMentality 
    ? applyMentalityToTeam(homeTeam, tactics.homeMentality) 
    : homeTeam;
  const at = tactics?.awayMentality 
    ? applyMentalityToTeam(awayTeam, tactics.awayMentality) 
    : awayTeam;
  
  // Step 2: Build complete tactics
  const homeTactics = tactics?.home 
    ? buildMatchTactics(ht, tactics.home) 
    : buildMatchTactics(ht, {});
  const awayTactics = tactics?.away 
    ? buildMatchTactics(at, tactics.away) 
    : buildMatchTactics(at, {});
  
  // Step 3: Inject tactics into teams
  injectTacticsIntoTeam(ht, homeTactics);
  injectTacticsIntoTeam(at, awayTactics);
  
  // Step 4: Compute originPOS from formation + strategy
  const homeOriginPOS = computeOriginPOSForStarters(
    ht.players, homeTactics.formation, p, ht._strategy
  );
  const awayOriginPOS = computeOriginPOSForStarters(
    at.players, awayTactics.formation, p, at._strategy
  );
  
  // Apply originPOS
  ht.players.forEach((pl, i) => { pl.originPOS = homeOriginPOS[i]; });
  at.players.forEach((pl, i) => { pl.originPOS = awayOriginPOS[i]; });
  
  // Step 5: Initialize engine
  const md = await Engine.initiateGame(ht, at, p);
  
  // Step 6: Store metadata
  md._homeFormation = homeTactics.formation;
  md._awayFormation = awayTactics.formation;
  md._homeStrategy = homeTactics.strategy;
  md._awayStrategy = awayTactics.strategy;
  md._homeRoles = homeTactics.roles;
  md._awayRoles = awayTactics.roles;
  md._homeMentality = tactics?.homeMentality || 'balanced';
  md._awayMentality = tactics?.awayMentality || 'balanced';
  
  return md;
}
```

4. **validateTacticsCompatibility(tactics) — 战术合理性检查**:

```javascript
/**
 * Validate that the selected tactics are compatible.
 * Returns warnings for incompatible combinations.
 */
export function validateTacticsCompatibility(tactics) {
  const warnings = [];
  const { formation, strategy } = tactics;
  
  // Example: gegenpress + deep defensive line = contradictory
  if (strategy.pressingIntensity === 'much_more' && strategy.defensiveLine === 'deep') {
    warnings.push('高位压迫与深防线矛盾——压迫在对方半场进行但防线站位靠后');
  }
  
  // Example: tiki_taka + very_direct passing = contradictory
  if (strategy.tempo === 'very_slow' && strategy.passingDirectness === 'very_direct') {
    warnings.push('慢节奏与长传冲吊不匹配');
  }
  
  // Example: narrow formation + wingers = wasteful
  if (strategy.width === 'narrow' && (formation === '4-2-4' || formation === '4-3-3')) {
    warnings.push('窄宽度策略与边路阵型不匹配——边锋效率降低');
  }
  
  return { isValid: warnings.length === 0, warnings };
}
```

```javascript
/**
 * Get the active strategy for a team in the current match.
 * Convenience accessor used by actions.js and playerMovement.js.
 */
export function getActiveTeamStrategy(matchDetails, side) {
  if (side === 'home') {
    return matchDetails._homeStrategy;
  }
  // Determine which engine team is "away"
  const homeTeamName = matchDetails._homeTeamName;
  if (matchDetails.kickOffTeam?.name === homeTeamName) {
    return matchDetails.secondTeam?._strategy || matchDetails._awayStrategy;
  }
  return matchDetails.kickOffTeam?._strategy || matchDetails._awayStrategy;
}
```
