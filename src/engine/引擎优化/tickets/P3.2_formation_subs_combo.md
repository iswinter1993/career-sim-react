# Phase 3.2: 实现变阵联动换人 — 一键双操作

**Phase**: 3 (FM级别换人)
**优先级**: P2
**阻塞**: P2.3 (formationChange), P3.1 (substitution)
**被阻塞**: P3.3

## 描述

FM中最常见的战术操作之一是"变阵+换人"组合——换下一个后卫，上一个中场，同时变阵为4-3-3。本ticket实现 `applyFormationChangeWithSubs()` 联合操作，确保变阵和换人原子化执行。

## 背景

单独换人或单独变阵是简单的，但组合操作需要仔细处理：
- 先变阵还是先换人？顺序影响originPOS计算
- FM的处理方式：先移除被换下球员→用新阵容重新计算originPOS→放入替补球员
- 例如：4-4-2换下CM上ST，同时变4-3-3 → 新球员获得4-3-3阵型的ST位置

```javascript
/**
 * Apply formation change together with one or more substitutions in a single atomic operation.
 * This mirrors FM's half-time tactical change which often combines both.
 *
 * @param {object} matchDetails
 * @param {'home'|'away'} side
 * @param {Array<{playerOutID: string, playerIn: object}>} substitutions — 1-5 subs
 * @param {string} newFormation — new formation key
 * @param {object} subTracker
 * @param {number} minute
 * @param {object} [pitchSize]
 * @returns {{matchDetails, subTracker, success: boolean}}
 */
export function applyFormationChangeWithSubs(
  matchDetails, side, substitutions, newFormation, subTracker, minute, pitchSize
) {
  const p = pitchSize || DEFAULT_PITCH;
  const teamKey = getTeamKey(matchDetails, side);
  const team = matchDetails[teamKey];
  
  // 1. Remove outgoing players
  const remainingPlayers = team.players.filter(
    pl => !substitutions.some(s => s.playerOutID === pl.playerID)
  );
  
  // 2. Compute new originPOS for the remaining + incoming players
  // First, determine final position set
  const finalPositions = [
    ...remainingPlayers.filter(pl => pl.currentPOS[0] !== 'NP').map(pl => ({ position: pl.position || 'CM' })),
    ...substitutions.map(s => ({ position: s.playerIn.position })),
  ];
  
  const newOriginPOS = computeOriginPOSForStarters(finalPositions, newFormation, p);
  
  // 3. Assign originPOS: remaining players first, then subs
  let posIdx = 0;
  for (const player of remainingPlayers) {
    if (player.currentPOS[0] === 'NP') continue;
    player.originPOS = newOriginPOS[posIdx];
    player.intentPOS = [...newOriginPOS[posIdx]];
    posIdx++;
  }
  
  // 4. Build and insert substitutes with assigned positions
  for (const sub of substitutions) {
    const subPlayer = buildPlayerJson(sub.playerIn, newOriginPOS[posIdx], {
      isSubstitute: true,
      subbedOnMinute: minute,
      replacedPlayerID: sub.playerOutID,
    });
    subPlayer.currentPOS = [...newOriginPOS[posIdx]];
    
    const outIdx = team.players.findIndex(pl => pl.playerID === sub.playerOutID);
    team.players[outIdx] = subPlayer;
    
    subTracker.subbedOutPlayerIDs.add(sub.playerOutID);
    posIdx++;
  }
  
  // 5. Update formation tag
  matchDetails[side === 'home' ? '_homeFormation' : '_awayFormation'] = newFormation;
  
  // 6. Track all substitutions in one window
  subTracker.playersUsed += substitutions.length;
  subTracker.windowsUsed++;
  const names = substitutions.map(s => `${s.playerIn.name} → ${s.playerOutID}`).join(', ');
  matchDetails.iterationLog.push(
    `TACTICAL: ${team.name} switch to ${newFormation} with ${substitutions.length} subs (${names})`
  );
  
  return { matchDetails, subTracker, success: true };
}
```
