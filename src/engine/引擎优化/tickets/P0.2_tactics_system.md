## 描述

创建 `engine/lib/tactics.js` 模块，实现FM风格的三层AI架构的数据定义和策略应用逻辑。包含：Team Strategy（球队指令）、Player Role（球员角色定义）、Player Trait（个人习惯/特质）。

## 背景

FM的AI系统分为三层：Team Style > Role > Individual。当前引擎无此概念——所有球员行为仅由position + 硬编码的11项动作权重 + 随机选择决定。战术层面仅有mentality对技能值的百分比修饰，远不足以模拟FM深度的战术差异。

## 实现内容

### 文件: `D:\newgame\career-sim-react\src\engine\lib\tactics.js`

1. **Team Strategy 定义**:
   - `DEFAULT_STRATEGY` 对象: { mentality, tempo, pressing, defensiveLine, width, passingStyle, fluidity, creativeFreedom }
   - `applyTeamStrategy(team, strategy, pitchSize)` — 对全队应用策略参数
   - `applyMentalityModifiers(team, mentality)` — 心态→技能修饰（现有逻辑迁移+增强）
   - `applyPressingModifiers(team, pressing, pitchSize)` — 压迫→防守intentPOS偏移
   - `applyTempoModifiers(team, tempo)` — 节奏→动作风险偏好
   - `applyWidthModifiers(team, width, pitchSize)` — 宽度→阵型X扩展
   - `fluidityToFactor(fluidity)` → 流动性→位置纪律系数(0.1-1.0)
   - 辅助函数: `mentalityToDepthFactor()`, `mentalityToIntentMap()`

2. **Player Role 定义** — `POSITION_ROLES` 对象:
   - 每个位置定义3-5个可用角色
   - 总计约50+角色，覆盖GK/CB/LB/RB/CDM/CM/CAM/LM/RM/LW/RW/ST
   - 每个角色包含: `actionProfile`（动作权重修饰）, `movementBias`（x/y偏移）, `zoneTolerance`（活动范围容忍度）
   - API: `getRoleModifier(action, position, role)`, `getRoleMovementBias(position, role)`, `getRoleZoneTolerance(position, role)`, `getDefaultRole(position)`, `getAvailableRoles(position)`

3. **Player Trait 定义** — `PLAYER_TRAITS` 对象:
   - 30+种球员习惯，分类为: 射门(5), 传球(4), 移动(10), 防守(4), 技术(5)
   - 每个trait包含: `action`（覆盖动作）, `overrideChance`（触发概率0.1-0.35）, `condition`（触发条件）, `modifier`（属性加成）
   - API: `evaluateTraitOverride(player, traitName, matchContext)`, `evaluateCondition(condition, player, matchContext)`, `getAllTraits()`
