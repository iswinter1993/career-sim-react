## 实现内容

### 文件: `D:\newgame\career-sim-react\src\engine\lib\formation.js`

在P0.1创建的矩阵基础上，完成以下API：

1. **`getFormationSlots(formationName)`**:
   - 返回阵型的11个位置槽位数组
   - 每个槽位: `{ pos: 'CM', slotKey: 'CML', x: 200, y: 380 }`
   - slotKey区分同位不同边（如CBL vs CBR）

2. **`getFormationPositions(formationName, pitchSize, mentality)`**:
   - 返回 `{ GK: [340, 50], CB: [240, 150], CM: [200, 380], ... }`
   - 合并同位置多槽位（两个CB → 输出两个不同的[x,y]）
   - 应用mentality线深调节
   - 应用pitchSize缩放（如果不提供则默认680×1050）

3. **`computeOriginPOSForStarters(starters, formationName, pitchSize)`**:
   - 输入: starters数组 `[{position: 'ST'}, {position: 'CM'}, ...]`
   - 输出: `[[280, 600], [200, 380], ...]` 与输入顺序一致
   - 自动处理: 两个CB分配CBL和CBR位置

4. **`getAdjustedLineY(baseY, mentality, pitchHeight)`**:
   - 心态→Y坐标调节百分比
   - ultra_attack: ×1.15, attack: ×1.07, balanced: ×1.0, defend: ×0.93, ultra_defend: ×0.85
   - 仅影响非GK位置

5. **`getAvailableFormations()`** → 返回所有可用阵型名称列表

6. **`getFormationLabel(formationName)`** → 返回阵型中文标签
