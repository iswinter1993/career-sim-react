# Phase 0.4: 扩展 validate.js — 12位置校验

**Phase**: 0 (基础设施)
**优先级**: P0
**阻塞**: P0.3 (需要positionGroup.js)
**被阻塞**: P1.5

---

## 描述

扩展 `engine/lib/validate.js` 的位置校验逻辑，使其识别并正确验证全部12个球员位置。这是所有位置相关改造的准入条件。

## 背景

当前 `validate.js` 仅校验引擎原生的8个位置（GK, CB, LB, RB, CM, LM, RM, ST）。CDM/CAM/LW/RW 在初始化时会通过校验（因为引擎使用了宽容的默认值），但不会被显式识别。需要更新校验逻辑以明确支持12个位置。

## 实现内容

### 文件: `D:\newgame\career-sim-react\src\engine\lib\validate.js`

1. **导入 positionGroup.js**:
   ```javascript
   import { ALL_POSITIONS } from './positionGroup.js';
   ```

2. **更新位置校验**:
   - 将硬编码的8个位置列表替换为 `ALL_POSITIONS` (12个)
   - 在球员校验函数中，验证 `player.position` 是否在 `ALL_POSITIONS` 中
   - 如果不是合法位置，默认映射到CM而非报错（保持向后兼容）

3. **新增校验**:
   - `validateFormationName(name)` — 验证阵型名称是否有效
   - `validateRoleName(position, role)` — 验证角色是否对该位置有效
   - 球队人数校验保持11人不变

4. **改进错误消息**: 包含具体的非法位置名称和合法位置列表

## 验收标准

- [ ] `ALL_POSITIONS` 包含12个位置
- [ ] 使用CDM/CAM/LW/RW的球员通过引擎校验
- [ ] 无效位置被自动映射到CM而非崩溃
- [ ] 球队必须恰好11名球员
