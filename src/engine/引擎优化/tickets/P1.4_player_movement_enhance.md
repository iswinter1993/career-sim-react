## 描述

在 `playerMovement.js` 的意图位置(intentPOS)计算和移动行为中引入位置分组差异，使防守球员/中场/进攻球员/边路球员在无球跑动时表现出不同的战术行为。

## 背景分析

当前 `playerMovement.js` 中：
- `getRunMovement()` 仅通过 `originPOS[1] > pitchHeight/2` 判断进攻方向（二分法）
- `getSprintMovement()` 同上，不区分位置
- `setIntentPosition()` 的 `setDefenceRelativePos()` / `setAttackRelativePos()` / `setLooseintentPOS()` 对全队所有球员使用相同的压缩系数
- 结果：CB和ST在无球时对球的反应程度相同

理想行为：防守球员向球线靠拢时有更大的回退倾向，进攻球员前插幅度更大，边路球员更注重宽度保持。

## 实现内容

### 文件: `D:\newgame\career-sim-react\src\engine\lib\playerMovement.js`

1. **添加导入**:
   ```javascript
   import { getPositionGroup, isDefensivePosition, isMidfieldPosition, isAttackingPosition, isWidePosition } from './positionGroup.js';
   ```

2. **`getRunMovement()` 位置差异化**:

   现有逻辑：球近(60px内)→追球；球远→回到intentPOS
   
   增强：
   - 防守球员(GK/CB/FB/DM)：球远时更早回到intentPOS（防守纪律），球近时更谨慎（不盲目压上）
   - 中场球员(CM/CAM/LM/RM)：平衡——既参与进攻也回防
   - 进攻球员(ST/LW/RW)：球远时留在进攻位置，球近时积极前插
   - 边路球员：更注重X方向(width)保持

3. **`getSprintMovement()` 位置差异化**:

   类似run，但速度更快，体能消耗更大：
   - 防守球员：仅在回追/压迫时冲刺
   - 进攻球员：前插和反击时更频繁冲刺
   - 体能低的球员(<30)减少冲刺频率

4. **`setDefenceRelativePos()` 防守压缩差异化**:

   ```
   防守球员: compressFactor = 0.15 (更紧的防守阵型)
   防守中场: compressFactor = 0.20
   中场:     compressFactor = 0.25
   进攻球员: compressFactor = 0.35 (留在前面准备反击)
   ```

5. **`setAttackRelativePos()` 进攻推挤差异化**:

   ```
   防守球员: pushFactor = 0.20 (谨慎前移)
   中场:     pushFactor = 0.35 (参与进攻)
   边路球员: pushFactor = 0.40 + X方向扩展 (宽度保持)
   进攻球员: pushFactor = 0.45 (全力前压)
   ```

6. **`setLooseintentPOS()` 球权争夺时差异化**:

   ```
   离球最近球员: 直接追球
   防守球员:     以防守站位为优先，适度向球靠拢
   中场球员:     向球方向压缩
   进攻球员:     留在前方等待反击机会，不过度回追
   ```

## 验收标准

- [ ] 防守球员在球远离时的回退倾向明显高于进攻球员
- [ ] 进攻球员在反击时前插幅度明显高于防守球员
- [ ] 边路球员保持较好的宽度纪律
- [ ] GK的移动行为不变（保持在球门前区域）
- [ ] 体能消耗逻辑不变（fitness递减保持）
