# ADR 0003 — 属性系统迁移到 0-100

**日期**: 2026-08-06  
**状态**: Accepted  
**决策者**: 用户 + AI Agent  

---

## 背景

现有属性系统（`src/attributes.js`）使用 0-20 值域，15 项子属性分属技术/身体/精神三类。`footballsimulationengine` 使用 0-100 值域，10 项独立技能。两套系统值域不兼容，无法直接对接。

## 决策

### 1. 保留三层分类，值域迁移到 0-100

用户选择"保留三层分类（技术/身体/精神），把每项子属性改为 0-100"。这意味着：

- 15 项子属性值域：0-20 → 0-100
- 位置权重表相应缩放
- `initAttributes` 和 `tickAttributes` 中的范围常量全部更新

**Why**: 
- 用户已熟悉三层分类 UI，不希望改变认知模型。
- 0-100 与 footballsimulationengine 技能值域一致，方便映射。
- 更细的粒度可以让微小进步可见（0-20 的精度不够）。

### 2. 15 项子属性 → 10 项引擎技能的加权映射

```
球员子属性（0-100）              引擎技能（0-100）
─────────────────────────       ─────────────────
盘带       ──────────────→      control
传球       ──────────────→      passing
射门       ──────────────→      shooting
控球       ──────────────→      control
抢断       ──────────────→      tackling
定位球      ──────────────→      penalty_taking (并影响 shooting 加成)
速度       ──────────────→      agility
力量       ──────────────→      strength
耐力       ──────────────→      影响 fitness
弹跳       ──────────────→      jumping
对抗       ──────────────→      strength
视野       ──────────────→      perception
冷静       ──────────────→      penalty_taking (点球冷静)
决断       ──────────────→      perception
领导力      ──────────────→      (无直接映射，影响 team intent 权重)
```

多对一映射的子属性取加权平均。具体权重由位置决定——例如 ST 的射门权重高，CB 的抢断权重高。

**Why**: 
- 映射表提供清晰的转换契约，方便调试和调校。
- 位置相关权重让同一子属性在不同位置的映射效果不同。

### 3. 赛后评分增量 + 赛季 tickAttributes 叠加

赛后评分触发的增长和赛季末 `tickAttributes` 的增长是**加法叠加**。两者独立计算，互不影响。

**Why**: 
- 赛季增长反映长期训练效果（缓慢、稳定）。
- 赛后增长反映比赛经验（爆发性、不均衡）。
- 叠加后总体增长仍然受潜力值和成长曲线限制。

### 4. 队友随机生成规则

队友属性使用高斯分布（均值 = 联赛水平 ± 位置变差），确保比赛有竞争力但不失随机性。

**Why**: 
- 后期需要接入真实数据时，只需替换生成函数，不影响下游。
- 均值随联赛水平调整保证不同联赛的比赛难度合理。

## 后果

### 正面

- 统一值域让属性 UI、引擎映射、赛后增长都使用同一尺度，减少转换错误。
- 保留三层分类保证向后兼容。
- 明确的映射表降低跨系统调试成本。

### 负面

- 需要迁移 `initAttributes`、`tickAttributes`、位置权重矩阵、UI 渲染等涉及值域的多处代码。
- 0-100 值域需要调整 UI 显示（原来是 0-20 的条形图，现在需要更多的视觉粒度）。
- 现有存档的 0-20 属性值无法直接转换（种子驱动，可以重新生成）。

### 迁移策略

因为属性系统完全由种子驱动（同一种子总是产出相同结果），现有存档只需重新执行 `initAttributes` 即可得到新的 0-100 值。玩家不会丢失进度——只有 UI 显示的数字变化。
